Why prove anything?

"log n grows much more slowly than n²" is a good intuition. But intuition can be wrong - small n mislead (n³ beats 2ⁿ up to n = 9), and slow growth is still growth (log n is unbounded). Big O, Ω and Θ have precise definitions, and a claim like log₂ n ∈ O(n²) is proven by exhibiting two numbers: a constant c and a starting point n₀.

Big O, formally

Definition. For functions f(n) and g(n): f(n) ∈ O(g(n)) if there exist constants c > 0 and n₀ > 0 such that 0 ≤ f(n) ≤ c·g(n) for every n ≥ n₀.

Read it as a game: you pick c and n₀ first, then the inequality has to survive every n from n₀ onward. c absorbs constant factors; n₀ lets you ignore a finite number of small inputs.

You do not need the smallest c or n₀. Any constants that make the inequality true for every n ≥ n₀ are a complete proof. Simple, generous choices (c = 10, n₀ = 1) are usually the easiest to justify.

A worked proof: log₂ n ∈ O(n²)

  1. We need constants c > 0 and n₀ > 0 such that log₂ n ≤ c·n² for every n ≥ n₀.
  2. Choose c = 1 and n₀ = 1.
  3. For n ≥ 1: n ≤ 2ⁿ, so taking log₂ of both sides, log₂ n ≤ n.
  4. For n ≥ 1: n ≤ n·n = n².
  5. Therefore log₂ n ≤ n ≤ n² = 1·n² for every n ≥ 1 (and log₂ n ≥ 0 there).
  6. So log₂ n ∈ O(n²). ∎

The intuition "log n grows much more slowly than n²" told us what to expect. Steps 3-5 are what actually prove it.

"For every n ≥ n₀" - the most important words

Here is a broken "proof" that n² ∈ O(n): choose c = 10; then n² ≤ 10n; therefore n² ∈ O(n).

n² ≤ 10n only holds up to n = 10. Big O requires the inequality for all n ≥ n₀, not merely on some finite range - and no bigger c helps, because n² ≤ c·n means n ≤ c, which fails as soon as n > c. A constant that "works for a while" proves nothing.

Bounding constants and lower-order terms

To show 3n² + 5n + 2 ∈ O(n²), replace every lower-order term by a multiple of n² that is at least as big once n ≥ 1:

For n ≥ 1:   5n ≤ 5n²     and     2 ≤ 2n²
So:          3n² + 5n + 2 ≤ 3n² + 5n² + 2n² = 10n²
Choose:      c = 10,  n₀ = 1

The trick works because for n ≥ 1, every smaller power of n is at most n². With logs, start at n₀ = 2 so that log₂ n ≥ 1 (log₂ 1 = 0). A smaller c is possible with a larger n₀ (e.g. c = 4 from n₀ = 6) - both are valid.

Big Ω, formally

Definition. f(n) ∈ Ω(g(n)) if there exist constants c > 0 and n₀ > 0 such that 0 ≤ c·g(n) ≤ f(n) for every n ≥ n₀.

The inequality points the other way: c·g(n) sits below f(n). Example: n² + 3n ∈ Ω(n²) - since 3n ≥ 0, we have 1·n² ≤ n² + 3n for n ≥ 1, so c = 1, n₀ = 1. For lower bounds, a smaller c is the safe direction (c = 2 would fail from n = 4).

Big Θ, formally

Definition. f(n) ∈ Θ(g(n)) if there exist constants c₁ > 0, c₂ > 0 and n₀ > 0 such that 0 ≤ c₁·g(n) ≤ f(n) ≤ c₂·g(n) for every n ≥ n₀.

Θ requires both an upper and a lower bound. For 3n² + 5n + 2 ∈ Θ(n²): the lower bound uses 5n + 2 ≥ 0, so 3n² ≤ f(n) (c₁ = 3); the upper bound is the computation above (c₂ = 10); both hold for n ≥ 1. Proving only f(n) ≤ 10n² shows O(n²) - not Θ(n²).

Disproving a claim

Not every claim is true. To show n² ∉ O(n), assume constants exist and derive a contradiction:

Suppose n² ≤ c·n for every n ≥ n₀.
Divide by n > 0:   n ≤ c   for every n ≥ n₀.
But n = max(n₀, c) + 1 is ≥ n₀ and > c.   Contradiction - no constants exist.

The pattern: divide by g(n) to get f(n)/g(n) ≤ c, then show the ratio grows without bound, so no fixed c can stay above it. The same idea disproves 2ⁿ ∈ O(n³), n! ∈ O(2ⁿ) and n ∈ O(log n).

Three kinds of argument - keep them apart

KindExample for log₂ n ∈ O(n²)Is it a proof?
Intuitive growth comparison"log n grows much more slowly than n²"; a table or graphNo - it covers finitely many n, or none
Constant-based definition proof"For n ≥ 1, log₂ n ≤ n ≤ n², so c = 1, n₀ = 1."Yes - it exhibits c and n₀ and covers every n ≥ n₀
Limit-based argument"lim log₂ n / n² = 0, so log₂ n ∈ O(n²)."Yes, via the limit theorem - a different route from the definition

The ratio method and limits

Look at f(n)/g(n) as n grows. For log₂ n / n²: 0, 0.25, 0.125, 0.047, 0.016 at n = 1, 2, 4, 8, 16 - it shrinks. That observation is still intuition. The limit makes it precise:

limn→∞ log₂(n) / n² = 0  ⇒  log₂(n) ∈ O(n²)
If L = lim f(n)/g(n) is …then
0f ∈ O(g), but not Ω(g) or Θ(g)
a positive constantf ∈ Θ(g) - so both O(g) and Ω(g)
∞f ∈ Ω(g), but not O(g) or Θ(g)

Why it works: if f/g → L < ∞, then eventually f/g < L + 1, i.e. f(n) ≤ (L + 1)·g(n) for every large n - the definition with c = L + 1. (If the limit doesn't exist, the test is silent and you go back to the definition.)

From T(n) to a proof

Pseudocode → operation counting → T(n) → asymptotic hypothesis → formal proof → O / Ω / Θ classification

In T(n) Analysis you derive an exact count such as T(n) = 3n² + 5n + 2 and read off the hypothesis Θ(n²). After solving a T(n) exercise, press Prove its complexity: you then prove T(n) ∈ O(n²) and T(n) ∈ Ω(n²) with explicit c₁, c₂ and n₀ - only then is Θ(n²) established.
