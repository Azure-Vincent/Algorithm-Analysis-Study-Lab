The course pseudocode convention (Style → Course convention) 
procedure linear search(x: integer, a1, a2, …, an: distinct integers)
i := 1
while (i ≤ n and x ≠ a_i)
    i := i + 1
if i ≤ n then location := i
else location := 0
return location
  • a1, a2, …, an in the header is one sequence, indexed from 1; n is its length. Write a term as a_i, a_{j+1}, ai or a[i].
  • := assigns, = compares; ≤ ≥ ≠ work (or <= >= !=).
  • One-line if … then … / else …; for i := 1 to n or for i in 2 to sqrt(n); interchange a_j and a_{j+1}.
  • {text in braces} is a comment. The body may sit at the same indentation as procedure, as on the slides.
  • “Not found” is position 0 in this convention, because positions start at 1.
